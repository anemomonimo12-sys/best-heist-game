Midnight Gilt — an original top-down stealth heist game in plain HTML, CSS and JavaScript with zero assets and zero network: sneak Wren the thief through three hand-planned floors of the Meridian Gallery, stay out of patrolling wardens vision cones and sweeping camera cones, keep the alarm meter down in the carpet shadows, use vent shortcuts, coin decoys and camera sparks, crack the prize cases for the Empress Tiara, the Tsars Egg and the Star of Meridian, pocket side loot, and reach the getaway door for time and ghost bonuses. All sound is synthesised in code.

## Run it

```sh
node main.ts   # writes the game dossier (dossier.json + screenshots); open game/index.html to play
```
